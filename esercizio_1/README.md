COMANDI USATI

gh auth status: controlla se ci sono altri account di git loggati

cd: spostarsi tra le varie directory

git init: crea il git

git config user.mail
git config user.name

git add .: salvare le modifiche

git commit -m: commentare le modifiche con un messaggio

 git remote add origin https://github.com/albe-rello/Verifica-5-AT-i-Levati-Alberto.git serve per aggiungere i file ad una repo gia esistente

git branch -M main

git push -u origin main: serve per caricare i file nella repo e mostrarli

gh auth login: collegare git hub a git bash
